# ATM Management System

This project is a simple ATM management system with a client-server architecture.

## Project Structure

- `client/`: Contains the client-side GUI application.
- `server/`: Contains the server-side logic and API.
- `database/`: Contains the database setup and migration scripts.

## Getting Started

1. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
2. **Initialize the database**:
   ```bash
   python database/database.py
   ```
3. **Run the server**:
   ```bash
   python server/main.py
   ```
4. **Run the client**:
   ```bash
   python client/main.py
   ```
